# Documentação — Plataforma de Contratos

Vault de documentação do projeto (abre no Obsidian). Separado da pasta
`codigo/`, que é o projeto Next.js publicado na Vercel.

## Navegação

- [[Escopo]] — o que é, fluxo de trabalho, o que está pendente
- Solicitações por data:
	- [[2026-09-30]] — criação da plataforma, import da planilha, murais
- [[Manual-Tecnico]] — stack, banco, deploy, import, manutenção
- [[Manual-Usuario]] — como usar cada tela
- [[Normalizacao]] — decisões tomadas ao migrar a planilha, item a item

## Como manter atualizado

Cada alteração pedida ganha uma entrada no arquivo do dia em
**Solicitações por Data**, com `- [x]` se concluída ou `- [ ]` se pendente.
O [[Escopo]] lista os `[ ]` em aberto — ao fechar um, atualize os dois.

> O repositório é **público**. Nada de valor, senha, CPF ou planilha real
> vai para o git — os dados ficam só no Supabase.
